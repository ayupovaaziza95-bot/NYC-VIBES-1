# NYC VIBES

Интерактивный электронный путеводитель по Нью-Йорку.

## Об авторе
Автор: Аюпова Азиза Руслановна
Год разработки: 09.10.2026

## О проекте
NYC VIBES — веб-сайт для самостоятельных путешественников,
который помогает познакомиться с главными достопримечательностями
Нью-Йорка с помощью готового четырёхдневного маршрута.

## Основные функции
- Четырёхдневный туристский маршрут по Нью-Йорку
- Интерактивная карта достопримечательностей
- Карточки объектов с подробными описаниями
- Фотографии и интересные факты
- Практическая информация: адреса, стоимость и часы работы
- Аудиогид для отдельных достопримечательностей

## Используемые технологии
- HTML5
- CSS3
- JavaScript
- Leaflet
- OpenStreetMap
- ElevenLabs
- Visual Studio Code
- Netlify
